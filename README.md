# 💳 ATM_APP

Aplicación de cajero automático (ATM) desarrollada en **Python** con interfaz gráfica moderna usando **ttkbootstrap**.  
Permite a los usuarios iniciar sesión con nombre y PIN, realizar depósitos, retiros, consultar balance y visualizar un historial de movimientos en una tabla interactiva.

---

## 🚀 Características
- Login estilizado con **ttkbootstrap**.
- Menú principal con bienvenida personalizada al cliente.
- Botones modernos y compactos para:
  - 💰 Depósito
  - 💸 Retiro
  - 📊 Consulta de balance
  - ❌ Salir de la aplicación
- Ventanas secundarias para ingresar montos de depósito y retiro.
- Historial de transacciones en **Treeview** (tipo, monto, fecha).
- Confirmación elegante al salir de la aplicación.
